### 4.2 int8 is rejected — with the control that makes it conclusive

| Arm | top-1 | top-3 |
|---|---|---|
| fp32 PyTorch (control) | 0.7500 | 0.8500 |
| ONNX fp32 | 0.7500 | 0.8500 |
| **ONNX int8 (dynamic)** | **0.0500** | **0.1250** |

The fp32 control matching PyTorch *exactly* proves the measurement pipeline is
sound, so the collapse is a genuine quantisation effect — ViT attention needs more
dynamic range than int8 weights provide. **Do not retry int8 without a different
scheme (static quantisation with calibration, or fp16).** fp16 is untested and
would halve the encoder to ~173 MB; it is a legitimate optimisation to try.

## 6 · Why the emulator cannot be used here

**This host has no `/dev/kvm`**, so the x86_64 emulator runs QEMU-TCG. Two
consequences:

1. It is far too slow for a 1B model.
2. Its guest CPU **lacks AVX and F16C**, and ggml compiles AVX2 in
   unconditionally when cross-compiling — so an AVX2-built ggml **SIGILLs inside
   the guest**. `app/src/main/cpp/CMakeLists.txt` pins x86_64 to the **SSE4.2
   baseline** for this reason. Do not remove that block.

That is why the engine is split so the same C++ builds as a host binary
(`tools/host_test.cpp`). **A real-device test on an arm64 phone remains the single
outstanding verification.**

## 8 · Hard constraints — do not re-litigate these

1. **Never hard-code a threshold, species count, dimension or version in the
   app.** Everything tunable comes from the manifest.
2. **Never reintroduce `AUTO_CONF = 0.80`.** On the whitened score scale
   precision peaks near 0.64–0.68 and **falls above 0.75**; 0.80 selects the worst
   decile. `tests/test_band_config.py` enforces this.
3. **Always show top-3. Never silently accept a species from a photo.** Top-1 is
   85.9%; `auto` means *higher confidence*, not *safe to accept*. A confident
   wrong ID yields a faithfully-formatted story about the wrong plant.
4. **The grounding pass is mandatory** (§4.4).
5. **The model never generates facts** — indicators come from the DB and only
   from the DB.
6. **A truncated or hash-mismatched artifact must never load**, and a partial
   download must never be promoted to current.
7. **Encoder and GGUF are never resident together.**
8. **Respect the protocol gate**: if the manifest's `backend` / `protocol` /
   `index_schema` is not one the shell implements, show **"app update required"**
   — never run a mismatched encoder and return plausible garbage.
9. **The app ships no model data.** `index.faiss` is deliberately excluded from
   the index tarball; the app does brute-force kNN in Kotlin.
10. **Keep the shell's files portable** — no absolute home paths in tracked files.
    `tests/test_workspace_hygiene.py` enforces this.
