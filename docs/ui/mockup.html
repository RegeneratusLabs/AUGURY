AUGURY · Android UI — as implemented

Six screens, all written and compiling in app/src/main/java/au/org/regeneratus/augury/ui/. This page is a visual record of that code: the palette, wording and layout come from the Compose sources, not from a design sketch.

Why this page exists and not a screenshot. This host has no /dev/kvm, so Android's x86_64 emulator refuses to run at all — “x86_64 emulation currently requires hardware acceleration” — with no software fallback. There is no way to execute the app on this machine, and therefore no way to capture a real screenshot here. What follows is the UI as the code defines it; it is a faithful rendering, not a photograph. The honest consequence: nobody has yet seen this app run.
